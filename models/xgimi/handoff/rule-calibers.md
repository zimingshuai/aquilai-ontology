# 规则口径表（判定面初始认知）

> 用途：让技能作者在实测前知道「哪些字段是规则回写、哪些判定可能无承载」；
> 技能落地时判定面须从 metadata_list_rules **现查推导**，本表不得沉淀为技能内清单快照。

| 规则名（含状态前缀） | 类型 | 上游实体 | 口径摘要 |
|---|---|---|---|
| 标准用量 | derived_property | BomLine | 标准用量 = BOM 行用量 ÷ BOM 基准数量；用量比较须在单位和基准数量一致后进行（§4.2 核心判断规则） |
| 订单未收货量 | derived_property | PurchaseOrder | 订单未收货量 = max(订单数量 − 累计有效收货量 − 已取消量 − 已关闭未收余量, 0)；订单收货转为库存后不再按原未收货数量重复计入（§4.3 ③） |
| 剩余新料需求 | derived_property | MaterialRequirement | 剩余新料需求 = 物料毛需求 − 替代满足量（主案例 Z9：20,000−6,000=14,000，加 Z9S 共 24,000）（§4.3 ④） |
| 新料缺口 | derived_property | MaterialRequirement | 新料缺口 = max(剩余新料需求 − 已分配新料供给, 0)（24,000−15,000=9,000）；不得因授权增加而新增供给（§4.3 ④+§11.8 测试四） |
| 待授权数量 | derived_property | MaterialRequirement | 待授权数量 = max(毛需求 − 已授权覆盖量, 0)（测试四：18,000−10,000=8,000；授权 v2 生效后 18,000−12,000=6,000）；授权单独核算、不作为物理供给（§4.3 步骤6） |
| 待授权参考金额 | derived_property | MaterialRequirement | 待授权参考金额 = 待授权数量 × 参考单价（8,000×20=160,000 元）；供内部审核，不自动生成采购订单（§11.8 测试四+§2.1 场景24） |
| 本期期末量 | derived_property | PeriodSupplyBalance | 本期期末量 = 期初量 + 本期有效到货 + 其他有效流入 − 实际满足需求量 − 其他有效流出；初始库存只计入一次（§4.4 ①） |
| 本期未满足需求 | derived_property | PeriodSupplyBalance | 本期未满足需求 = 本期应满足需求 − 实际满足需求量；保留为逾期需求，后续结转不得重复累计（11 月 9,000 与 12 月底 7,800 分别展示）（§4.4 ①+§5.3.3） |
| 期末风险量 | derived_property | SlowMovingRisk | 风险量 = max(评估期末剩余量 − 经确认的保留量 − 经证实的期后消耗量, 0)；保留量与期后消耗量不得重复覆盖同一用途（§4.4 ②） |
| 呆滞风险金额 | derived_property | SlowMovingRisk | 风险金额 = Σ(风险数量 × 对应成本单价)；不等于减值损失或实际收益，敞口≠损失（§4.4 ④+§8 红线） |
| 方案合计敞口 | derived_property | SolutionPlan | 合计敞口 = 窗口内风险金额 + 窗口后未消化承诺（S2：24,000+64,000=88,000，不能宣称消除了 64,000 风险）；延期只是把旧料移出评估窗口（§11.7） |
| 模拟可减少风险量 | derived_property | SolutionPlan | 模拟可减少风险量 = max(不干预风险量 − 干预后风险量, 0)（8,000−2,000=6,000）；表示条件成立时可减少的量，不等同已实现收益（§4.5 ③） |
| 未归因数量 | derived_property | HistoricalCase | 未归因数量 = max(呆滞总量 − Σ各原因归因数量, 0)；各主要原因对应数量之和 ≤ 案例呆滞总量，无法确认的部分保留为未归因、不强行凑足总量（§4.5 ④+§8 防重复归因红线） |
| 呆滞风险触发复核 | trigger | SlowMovingRisk | 风险阈值为未覆盖数量大于 0，一次有效评估即可触发；风险首次可识别日即形成（§11.6 预期结果）；后续形成风险复核任务 |
| 工程变更预防检查触发 | trigger | EcnRecord | 已批准的工程变更导致未来旧料需求减少时，检查关联的未到货订单，计算无法被需求覆盖的数量并提示可取消数量、办理时间及截止日期；应在变更已获知且影响能够判断时触发、不等 BOM 生效（§5.4.7）；"旧料需求减少"的判定由运行时计算（OQ-02 派生） |
| 授权数量变化重核算 | trigger | InspectionChange | 同一授权对象及口径下比较前后数量，识别授权数量变化后重新核算相关待授权需求或策备建议（A_schema/inspection-rules.csv#授权数量变化） |
| 替代关系变化复核分配方案 | trigger | InspectionChange | 比较方向、范围、比例、有效期及批准状态，检查原分配方案是否仍然有效；失效替代关系保留问题记录，但不得参与替代计算（§4.2 异常处理+A_schema/inspection-rules.csv） |
| 冻结供给排除待核查 | trigger | Supply | 质检冻结库存未获放行不参与供给分配，单列待核查数量（1,000 颗/20,000 元），不认定为零风险或全额损失（§11.3 PS-1002） |
| 归因不得超案例总量 | admission | record_cause_attribution | 写前拦截——新归因数量不得超出案例未归因量（未归因 = max(呆滞总量 − Σ归因, 0)，即"各主要原因数量之和 ≤ 案例呆滞总量"红线）；拦截时动作拒绝执行并提示补充依据或调整数量（OQ-09 裁决，2026-10-14） |

共 19 条；名称带【待处理】/【待讨论】前缀的规则在技能侧引用时必须注明状态。
